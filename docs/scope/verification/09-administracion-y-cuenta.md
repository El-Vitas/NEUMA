# 09 · Administración y cuenta

Quién entra a la organización, con qué permisos, y qué controla cada persona sobre su propia cuenta.

> Leer `README.md` de esta carpeta antes de usar este documento. Los permisos de espacio y de página se revisan en `04-colaboracion-y-permisos.md`; aquí se revisa el nivel de la organización.

---

## AD-01 · Debe permitir incorporar personas a la organización

- [ ] Se puede invitar a alguien por correo
- [ ] Se pueden invitar varias personas de una vez
- [ ] Se ve el estado de cada invitación: enviada, aceptada, caducada
- [ ] Se puede reenviar una invitación
- [ ] Se puede cancelar una invitación pendiente
- [ ] Se puede invitar indicando ya a qué espacios entra
- [ ] Quien acepta llega a una pantalla que le explica dónde está

## AD-02 · Debe permitir administrar a los miembros

- [ ] Se ve la lista de miembros de la organización
- [ ] Se ve el rol de cada uno
- [ ] Se puede buscar y filtrar la lista
- [ ] Se puede cambiar el rol de una persona
- [ ] Se puede desactivar a una persona sin borrar lo que escribió
- [ ] Al desactivarla pierde el acceso de inmediato
- [ ] Se puede reactivar
- [ ] Se ve la última vez que cada persona entró

## AD-03 · Debe permitir agrupar personas

- [ ] Se pueden crear grupos de personas
- [ ] Se puede dar acceso a un espacio a un grupo completo
- [ ] Agregar a alguien al grupo le da el acceso sin tocar cada espacio
- [ ] Se ve a qué espacios alcanza cada grupo
- [ ] Se puede eliminar un grupo y se explica quién pierde acceso

## AD-04 · Debe permitir configurar la organización

- [ ] Se puede cambiar el nombre de la organización
- [ ] Se puede poner un logo
- [ ] Se puede definir el idioma por defecto
- [ ] Se puede definir si las páginas nuevas nacen privadas o visibles
- [ ] Se puede restringir quién puede crear espacios
- [ ] Se puede restringir quién puede invitar personas
- [ ] Se puede restringir quién puede publicar páginas hacia afuera

## AD-05 · Debe dejar rastro de lo que pasa

- [ ] Existe un registro de eventos administrativos
- [ ] Registra ingresos, invitaciones, cambios de rol y bajas
- [ ] Registra cambios de permisos de espacios
- [ ] Registra publicaciones hacia afuera y exportaciones masivas
- [ ] Cada entrada indica quién, qué y cuándo
- [ ] Se puede filtrar por persona y por fecha
- [ ] Solo lo ve quien administra
- [ ] No se puede editar ni borrar desde la interfaz

## AD-06 · Debe permitir sacar los datos de la organización

- [ ] Quien administra puede exportar toda la organización
- [ ] Se avisa cuando la exportación está lista
- [ ] La exportación queda registrada en el registro de eventos

---

## CU-01 · Debe permitir administrar el perfil propio

- [ ] Se puede cambiar el nombre visible
- [ ] Se puede poner una foto o avatar
- [ ] Se puede cambiar el correo, con confirmación
- [ ] Los cambios se reflejan de inmediato donde aparece la persona
- [ ] Se ve a qué organización y espacios se pertenece

## CU-02 · Debe permitir cuidar el acceso propio

- [ ] Se puede cambiar la contraseña
- [ ] Cambiarla exige la contraseña actual
- [ ] Se rechazan contraseñas débiles explicando por qué
- [ ] Existe recuperación de contraseña por correo
- [ ] Se ven las sesiones activas
- [ ] Se puede cerrar una sesión concreta
- [ ] Se pueden cerrar todas las sesiones de una vez
- [ ] Se puede cerrar sesión desde cualquier pantalla

## CU-03 · Debe permitir ajustar las preferencias propias

- [ ] Se puede elegir el idioma
- [ ] Se puede elegir el tema claro u oscuro
- [ ] Se puede elegir la zona horaria
- [ ] Se puede elegir el formato de fecha
- [ ] Las preferencias se recuerdan entre dispositivos

## CU-04 · Debe permitir controlar los avisos

- [ ] Se puede elegir qué avisos se reciben dentro de la aplicación
- [ ] Se puede elegir qué avisos llegan por correo
- [ ] Se pueden silenciar los avisos de un espacio
- [ ] Se pueden silenciar los avisos de una página
- [ ] Se puede desactivar todo de una vez
