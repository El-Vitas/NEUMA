# 08 · Plantillas

Crear con estructura desde el primer momento, sin armarla a mano cada vez.

> Leer `README.md` de esta carpeta antes de usar este documento.

Una plantilla es una página cualquiera guardada para repetirse: su contenido, sus propiedades, su ícono y sus subpáginas. No es un tipo aparte de objeto.

---

## TP-01 · Debe ofrecer plantillas al crear una página

**Cómo probarlo:** crea una página nueva y observa qué se ofrece antes de escribir nada.

- [ ] Al crear una página se ofrece elegir una plantilla
- [ ] También se puede empezar en blanco, sin pasos extra ni clics de más
- [ ] Las plantillas se ven con ícono, nombre y una línea de descripción
- [ ] Se puede previsualizar el contenido antes de aplicarla
- [ ] Al aplicarla, la página queda con su estructura, sus propiedades y su ícono
- [ ] El cursor queda listo para escribir en el primer lugar útil
- [ ] Se puede elegir plantilla también al crear una página hija
- [ ] La elección se puede deshacer de inmediato si fue equivocada

## TP-02 · Debe traer plantillas útiles de fábrica

- [ ] Tarea
- [ ] Proyecto
- [ ] Acta de reunión
- [ ] Documento técnico
- [ ] Wiki de equipo
- [ ] Registro de decisión
- [ ] Cada una llega con propiedades coherentes con su propósito
- [ ] Cada una llega con vistas ya configuradas cuando es una colección
- [ ] Cada una llega con contenido de ejemplo que orienta sin estorbar
- [ ] Todas están traducidas al español y al inglés
- [ ] Se pueden modificar después de aplicadas, sin restricciones

## TP-03 · Debe permitir crear una plantilla desde cero

- [ ] Existe un lugar visible donde se administran las plantillas
- [ ] Se puede crear una plantilla nueva
- [ ] Se le pone nombre, ícono y descripción
- [ ] Se edita igual que cualquier página
- [ ] Se le definen propiedades
- [ ] Se le agrega contenido en el cuerpo
- [ ] Se guarda y queda disponible al crear páginas

## TP-04 · Debe permitir convertir una página existente en plantilla

- [ ] Desde el menú de una página se puede guardarla como plantilla
- [ ] Se pregunta si se incluyen las subpáginas
- [ ] Se pregunta si se incluyen los valores actuales de las propiedades o solo su definición
- [ ] La página original no se modifica
- [ ] La plantilla creada aparece de inmediato en la lista

## TP-05 · Debe permitir administrar las plantillas

- [ ] Se ve la lista de plantillas disponibles
- [ ] Se puede editar una plantilla existente
- [ ] Se puede renombrar
- [ ] Se puede cambiar su ícono y su descripción
- [ ] Se puede duplicar
- [ ] Se puede eliminar, con confirmación
- [ ] Se ve quién la creó y cuándo se modificó por última vez
- [ ] Se puede reordenar cómo aparecen al crear una página
- [ ] Se puede ocultar una plantilla sin eliminarla

## TP-06 · Debe permitir encontrar la plantilla adecuada

- [ ] Se pueden buscar plantillas escribiendo
- [ ] Se agrupan por categoría, no en una lista plana
- [ ] Las usadas hace poco aparecen primero
- [ ] Se ve cuántas veces se ha usado cada una
- [ ] Sin plantillas aún, se explica cómo crear la primera

## TP-07 · Debe definir hasta dónde alcanza cada plantilla

- [ ] Una plantilla puede pertenecer a un espacio
- [ ] Una plantilla puede estar disponible en toda la organización
- [ ] Al crear una página solo se ofrecen las plantillas alcanzables desde ahí
- [ ] Se puede cambiar el alcance después de creada
- [ ] Quien no tiene permiso no puede editar ni eliminar plantillas ajenas

## TP-08 · Debe permitir plantillas de fila dentro de una colección

- [ ] Una colección puede tener sus propias plantillas de fila
- [ ] Al crear una fila se puede elegir entre ellas
- [ ] La plantilla trae las propiedades ya rellenadas
- [ ] La plantilla trae contenido en el cuerpo, no solo propiedades
- [ ] Se pueden tener varias plantillas distintas en la misma colección
- [ ] Se editan desde la propia colección, sin ir a otra pantalla

## TP-09 · Debe permitir una plantilla por defecto

- [ ] Se puede fijar qué plantilla usan las filas nuevas de una colección
- [ ] Con una por defecto, crear una fila la aplica sin preguntar
- [ ] Se puede igual elegir otra plantilla en el momento
- [ ] Se puede quitar la plantilla por defecto y volver a filas en blanco

## TP-10 · Debe resolver los valores que dependen del momento

- [ ] Una plantilla puede incluir la fecha de hoy, y se resuelve al aplicarla
- [ ] Puede incluir a quien la aplica como responsable
- [ ] Puede incluir la fecha en el título, resuelta al crear
- [ ] Estos valores quedan fijos en la página creada, no siguen cambiando
- [ ] Se ve en la plantilla que ese valor es dinámico

## TP-11 · Debe reproducir la estructura completa

- [ ] Una plantilla con subpáginas crea también esas subpáginas
- [ ] Una plantilla con una colección adentro la crea con su esquema y sus vistas
- [ ] Los enlaces internos de la plantilla apuntan a las páginas recién creadas, no a las de la plantilla
- [ ] Los adjuntos de la plantilla se copian a la página nueva
- [ ] La jerarquía anidada se respeta en el árbol lateral

## TP-12 · Debe permitir aplicar una plantilla después

- [ ] Una página vacía ofrece aplicar una plantilla
- [ ] En una página con contenido, se ofrece agregar la plantilla sin borrar lo escrito
- [ ] Se advierte antes de sobrescribir propiedades que ya tienen valor
- [ ] Se puede deshacer con Ctrl+Z

## TP-13 · Debe mantener independientes la plantilla y lo creado con ella

- [ ] Editar la plantilla no altera las páginas ya creadas
- [ ] Editar una página creada no altera la plantilla
- [ ] Eliminar la plantilla no afecta a las páginas creadas
- [ ] Se puede ver desde qué plantilla nació una página

## TP-14 · Debe permitir repetir estructura dentro de una página

- [ ] Se puede insertar un botón que crea contenido predefinido
- [ ] Se configura qué bloques agrega
- [ ] Se configura dónde los agrega
- [ ] Puede crear una fila en una colección en vez de bloques
- [ ] Al pulsarlo, el contenido aparece de inmediato
- [ ] Se puede editar la configuración del botón después

## TP-15 · Debe permitir partir un espacio con estructura

- [ ] Al crear un espacio se puede elegir una plantilla de espacio
- [ ] La plantilla crea las páginas y colecciones iniciales
- [ ] Se puede guardar un espacio existente como plantilla de espacio
- [ ] También se puede crear un espacio vacío
