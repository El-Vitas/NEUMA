# 05 · Grafo de conocimiento

Lo que convierte un montón de páginas en un cerebro: cómo se conectan entre sí.

> Leer `README.md` de esta carpeta antes de usar este documento. Las plantillas se revisan en `08-plantillas.md`.

---

## GR-01 · Debe registrar las conexiones entre páginas

- [ ] Mencionar una página desde otra crea la conexión
- [ ] Enlazar una página desde el texto también la crea
- [ ] Quitar la mención deshace la conexión
- [ ] La conexión aparece sin tener que recargar ni esperar de más
- [ ] Mover o renombrar una página no rompe sus conexiones
- [ ] Enviar una página a la papelera no deja conexiones apuntando al vacío

## GR-02 · Debe mostrar quién apunta a esta página

- [ ] La página muestra una sección de retroenlaces
- [ ] Cada retroenlace indica el título de la página de origen
- [ ] Se ve un fragmento del contexto donde aparece la mención
- [ ] Al hacer clic se navega a la página de origen
- [ ] Solo se listan páginas a las que uno tiene acceso
- [ ] El conteo mostrado coincide con lo que realmente se lista
- [ ] Sin retroenlaces, la sección no ocupa espacio inútil
- [ ] Con muchos retroenlaces se pueden recorrer sin que la página se alargue sin fin

## GR-03 · Debe mostrar menciones sin enlazar

- [ ] Se detectan páginas que nombran a esta sin haberla enlazado
- [ ] Se listan aparte de los retroenlaces reales
- [ ] Se puede convertir una de esas menciones en enlace con un clic
- [ ] Se puede descartar una sugerencia para que no vuelva a aparecer

## GR-04 · Debe permitir ver el grafo

- [ ] Existe una vista visual de páginas y conexiones
- [ ] Se puede centrar el grafo en una página
- [ ] Se puede ajustar la profundidad de conexiones mostradas
- [ ] Al hacer clic en un nodo se abre esa página
- [ ] Se puede filtrar por espacio
- [ ] Se puede buscar un nodo dentro del grafo
- [ ] Con muchas páginas sigue siendo legible y no se congela
- [ ] Se lee bien en modo oscuro

## GR-05 · Debe sugerir contenido relacionado

- [ ] La página sugiere otras relacionadas
- [ ] Se explica por qué se sugiere cada una
- [ ] Las sugerencias respetan los permisos
- [ ] Se pueden ocultar si no aportan
