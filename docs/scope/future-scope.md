# Neuma Future Scope

Nothing in this document is a current implementation task. These items are intentionally excluded from the current Neuma phase.

## Identity And Access

- Google Workspace SSO.
- Microsoft Entra SSO.
- External guests.
- Public sharing.
- Advanced page-level permission exceptions.
- Multiple organizations or multi-tenancy.

## Commercial Features

- Billing.
- Subscriptions.
- Plans.
- Commercial entitlements.

## Search And Infrastructure

- Embeddings.
- Semantic search.
- External search engines.
- Search analytics.
- Knowledge freshness scoring.
- S3-compatible object storage.
- CDN delivery.
- Valkey.
- BullMQ.
- Distributed collaboration nodes.

## Product Features

- Calendar and timeline collection views.
- Comments.
- Notifications.
- Inbox.
- Slack, GitHub, Jira, Linear, and calendar integrations.
- Public API keys.
- Webhooks.
- Plugin marketplace.
- Offline-first storage.
- Advanced analytics.

## Import And Compatibility

- Import/export with other documentation tools.
- Markdown import/export beyond the current editor contract.
- Compatibility migrations for external workspaces.
